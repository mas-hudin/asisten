💡 Pilihan Suara AI 100% GRATIS:

Buka aplikasi web ini di Microsoft Edge (ikon ombak di taskbar). Microsoft Edge menyertakan suara Bahasa Indonesia alami (Microsoft Gadis / Ardi Natural) yang fasih secara 100% GRATIS seumur hidup tanpa biaya langganan!

Teknologi Tampilan Visual Avatar

D-ID mengubah foto Ibu Siska menjadi video orang hidup dengan bibir bergerak secara presisi (Free Trial di d-id.com).

Pasang Robot AI di Website Sekolah

Salin kode di bawah ini dan tempelkan ke website sekolah Anda (WordPress, Blogger, Web HTML, dll) untuk menampilkan robot AI ini.

Kode di bawah otomatis disesuaikan dengan URL hosting Anda agar siap pakai langsung di WordPress.

Metode 1: Floating Launcher Widget (Direkomendasikan)

Menampilkan tombol bulat melayang futuristik di pojok kanan bawah website sekolah yang dapat diklik untuk membuka jendela robot AI.

Metode 2: Iframe Tersemat Langsung

Menyisipkan robot AI sebagai kotak dialog langsung di halaman khusus (contoh: di halaman Kontak atau Halaman PPDB).

Backup, Restore & Keamanan

Ekspor dan amankan seluruh data sekolah ke file JSON, atau pulihkan data kapan saja.

💡 Tips Sinkronisasi ke Hosting GitHub & Website Sekolah:

Setelah Anda mengubah data sekolah di Panel Admin ini, klik "💾 Unduh File config.js untuk GitHub" di atas. Lalu upload/replace file config.js hasil unduhan tersebut ke folder js/ di repository GitHub Anda. Dengan begitu, seluruh siswa dan website sekolah (seperti widget di website utama) otomatis membaca data sekolah terbaru!
